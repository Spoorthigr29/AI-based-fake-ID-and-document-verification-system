# ML Models Directory

This directory holds model artifacts, model wrapper architectures, weights, and pre/post-processing pipelines for:
- OCR text detection and recognition (e.g. PaddleOCR / Tesseract configs)
- Biometric face feature extraction & embedding comparison (e.g. ArcFace / InsightFace)
- Digital image tampering & forensic classifiers (Error Level Analysis, Copy-Move, Splicing)
- Multi-signal explainable risk scoring heuristics

*Note: Heavy weight files (*.pt, *.onnx, *.h5) are ignored by git via `.gitignore`.*
